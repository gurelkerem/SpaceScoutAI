🚀 SpaceScout AI

SpaceScout AI is an automated space news intelligence platform that monitors recent developments in space exploration and astronomy.

The system collects space-related news, filters the latest articles from the last 24 hours, categorizes them, scores their importance, and automatically publishes a daily report using GitHub Actions and GitHub Pages.

🌌 Features

✅ Collects real-time space news from RSS feeds

✅ Filters news from the last 24 hours

✅ Automatically categorizes articles

✅ Assigns importance scores

✅ Generates HTML reports automatically

✅ Runs daily using GitHub Actions

✅ Publishes reports through GitHub Pages

✅ Accessible from any device with a web browser

🛰️ Categories

SpaceScout automatically classifies articles into categories such as:
